Questo esercizio ti guida attraverso i primi passi pratici con Rust, sia da riga di comando (cargo) sia usando un IDE come RustRover. Ecco cosa dovresti capire e come farlo, passo per passo:

🎯 Obiettivi dell'esercizio

  1. Imparare a creare un progetto Rust con cargo

  2. Capire la struttura base di un progetto Rust (incluso Cargo.toml)

  3. Scrivere e compilare un semplice programma Rust

  4. Familiarizzarti con RustRover e il debugger

🛠️ Come farlo passo per passo

✅ 1. Crea un nuovo progetto con cargo

Apri il terminale e digita:

bash
cargo new mio_progetto
cd mio_progetto

Questo crea una cartella con la struttura base di un progetto Rust.

✅ 2. Esplora la directory e Cargo.toml

Dai un’occhiata a cosa c’è nella cartella:

  • src/main.rs: contiene il main() con Hello, world!

  • Cargo.toml: contiene nome del progetto, versione e dipendenze

✅ 3. Compila ed esegui il "Hello, world!"

Nel terminale, esegui:

bash
cargo run

Dovresti vedere stampato Hello, world!

✅ 4. Modifica main.rs con questo codice:

rust
use rand::Rng;

fn main() {
    println!("Hello, world!");
    let mut rng = rand::thread_rng();
    let secret_number: u8 = rng.gen();
    println!("secret_number is {}", secret_number);
}

⚠️ Per farlo funzionare, devi aggiungere la libreria rand al file Cargo.toml. Aggiungi questa riga sotto [dependencies]:

toml
rand = "0.8"

Poi salva e esegui di nuovo:

bash
cargo run

✅ 5. Risolvi eventuali errori

Se il compilatore ti dà errori, leggi attentamente il messaggio. Puoi usare:

bash
cargo add --help
cargo --help

Oppure cerca nella documentazione suggerita nel riquadro Resources and Hints.

✅ 6. Ripeti in RustRover

Apri RustRover e:

  • Apri il progetto creato

  • Verifica il codice

  • Prova a eseguire con il debugger

  • Aggiungi un breakpoint nella riga let secret_number... e avvia in modalità debug

📚 Risorse utili

  • The Rust Book, Capitolo 1

  • Versione interattiva del libro

Se vuoi, posso aiutarti a configurare tutto passo per passo sul tuo computer. Fammi sapere che sistema operativo usi (Windows, macOS, Linux) oppure se stai già usando RustRover.

Nel frattempo, ti segnalo gli errori più comuni quando si lavora con il codice di esempio:

⚠️ 1. Errore: cannot find function 'rng'

Probabile causa: questa riga non è corretta:

rust
let mut rng = rand::rng();

✅ Soluzione corretta:

rust
let mut rng = rand::thread_rng();

⚠️ 2. Errore: no method named 'random' oppure no method named 'gen'

Causa: stai usando rng.random() ma il metodo corretto è rng.gen() dal trait Rng.

✅ Soluzione corretta:

rust
let secret_number: u8 = rng.gen();

Assicurati anche di importare:

rust
use rand::Rng;

⚠️ 3. Errore: cannot find crate 'rand'

Causa: manca la dipendenza nel Cargo.toml

ChatGPT ha detto:

Hai ricevuto questo errore perché hai scritto:

powershell
cd src/main.rs

Ma main.rs è un file, non una cartella, quindi PowerShell ti dice:

cd : Impossibile trovare il percorso 'src/main.rs' perché non esiste.

✅ Come risolvere

Se vuoi modificare main.rs, non devi usare cd, ma devi aprire il file con un editor. Ad esempio:

📝 In Visual Studio Code (se installato):

powershell
code src/main.rs

📝 Oppure in Notepad:

powershell
notepad src/main.rs

Oppure apri manualmente il file con il mouse nel file explorer (in mio_progetto/src/main.rs).

📌 Riassunto:

  • cd serve per entrare in cartelle, non file.

  • main.rs è un file, quindi si apre con un editor.

  • Dopo averlo modificato, torna nella root del progetto (cd .. da src) e lancia:

powershell
cargo run
